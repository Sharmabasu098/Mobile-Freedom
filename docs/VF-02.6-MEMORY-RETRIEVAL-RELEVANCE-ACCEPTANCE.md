# VF-02.6 — Memory Retrieval & Relevance

**Status:** Test-first scope locked on isolated branch  
**Branch:** `vf-02.6-memory-retrieval-relevance`  
**Base:** `main`  
**Safety:** No direct changes to `main`. No storage mutation is permitted during retrieval.

## Objective
Retrieve only stored memories that are useful for the current query or conversation context. Retrieval must be deterministic, relevance-focused, and must not silently alter stored memories.

## Acceptance Criteria

- **MR-01 — Current query/context analysis:** Retrieval uses the current user query and available active conversation context.
- **MR-02 — Relevant stored-memory retrieval:** Candidate memories relevant to the current request can be returned.
- **MR-03 — Irrelevant-memory exclusion:** Unrelated memories are excluded from results.
- **MR-04 — Exact-topic relevance:** Directly matching topic memories are prioritized.
- **MR-05 — Related-topic relevance:** Related memories may be included when they materially help answer the current request.
- **MR-06 — Project-context relevance:** Project-specific memories are selected when the request concerns that project; unrelated project memories are excluded.
- **MR-07 — Preference relevance:** Preferences are included only when they affect the current task.
- **MR-08 — Instruction relevance:** Applicable user instructions are surfaced; unrelated instructions are not.
- **MR-09 — Multiple relevant memories:** Multiple useful memories can be returned without losing relevant details or duplicating entries.
- **MR-10 — Conflicting memory handling:** Conflicting candidates are surfaced/handled safely; retrieval must not invent a resolution or silently overwrite either memory.
- **MR-11 — No-relevant-memory fallback:** Empty or irrelevant candidate sets produce a clear empty result/fallback, not unrelated memory.
- **MR-12 — Determinism and storage safety:** Retrieval behavior is repeatable for the same inputs and does not write, delete, mutate, or reorder persisted memory records.

| MR-T13 | Conflicting candidate memories | Conflict preserved/flagged; no invented winner |
| MR-T14 | Empty memory store | Safe empty fallback |
