## Locked parameters
- Minimum history: **7 valid, unique snapshots**
- Minimum span: **7 days**
- Method: **Robust Median Daily Growth** from adjacent snapshot pairs, using actual elapsed time; median rate projects from latest usage.
- Horizons: **7, 14, or 30 days** only; maximum 30 days.
- Capacity changes: do not predict capacity; withhold free-space forecast if capacity stability cannot be established.
- Irregular intervals: permissible if positive intervals, valid data, and minimum count/span gates are satisfied.
- Invalid records, duplicate IDs, non-positive intervals, insufficient data/span, unusable numeric values, or excessive noise: return safe no-prediction.
- Output must be clearly advisory and disclose method/limitations; no confidence claims.

## Acceptance criteria
AC-01 validated M12.2 history integration; AC-02 minimum-data gates; AC-03 determinism; AC-04 method transparency; AC-05 increasing/decreasing/stable handling; AC-06 irregular/noisy/outlier/excessive-noise safety; AC-07 capacity-change safety; AC-08 horizon validation; AC-09 numeric safety; AC-10 uncertainty/limitations; AC-11 M12.1–M12.3 regression; AC-12 typecheck; AC-13 production build; AC-14 CI; AC-15 scope safety.
